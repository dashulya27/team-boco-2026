# Полный проект TEAM BOCO — 1.4.1

Всё объединено: бумажная загадка → вход → игра с котами → шифр Виженера →
бинарный код → подарок. Игра и инструкции для игрока на немецком;
названия миссий и декоративные подписи частично на английском.

## Как заменить файлы через PhpStorm

1. Распакуй архив. Внутри находится папка `team-boco-2026`.
2. Открой в Проводнике уже клонированную папку:
   `PhpstormProjects\team-boco-2026`.
3. Скопируй **содержимое** папки из архива в эту существующую папку.
   Выбери замену совпадающих файлов и объединение папок. `index.html` должен
   лежать прямо в `team-boco-2026`, рядом с `game.html`, а не ещё на один уровень глубже.
   Существующую папку `.git` сохрани: в архиве её нет.
4. В PhpStorm выбери проект `team-boco-2026`. Правой кнопкой по `index.html` →
   **Open in Browser**. Открывается страница через `http://localhost:...`.
   Введи `SIMPLE`, нажми проверку, затем `SPIEL STARTEN`.
5. В этом же проекте открой **Commit** (`Ctrl+K`), отметь новые и изменённые
   файлы проекта, напиши `Unify BOCO birthday game` и выполни Commit.
6. Выполни **Push** (`Ctrl+Shift+K`) в `dashulya27/team-boco-2026`.
   Если PhpStorm запросит вход, войди в свой GitHub через браузер.
7. После успешного Pages-развёртывания открой:
   https://dashulya27.github.io/team-boco-2026/
   Проверь в приватном окне, чтобы начать с чистого прогресса.

В GitHub **Settings → Pages** при публикации из ветки источник — `main`,
папка — `/(root)`. Если текущий сайт уже так настроен, достаточно Push.
Дополнительный проект на GitHub создавать не нужно.

## Для ведущей — ответы и подготовка

1. Сначала выдать Цезаря и при необходимости колесо. Ответ:
   `DER SCHLUESSEL IST SIMPLE`. Во входе ввести только `SIMPLE`.
2. В игре нужно трижды отнести кота к двери: первый кот один раз возвращается.
3. После третьей доставки автоматически появится Виженер. Ключ — `SIMPLE`.
   Ответ — `DAS GESCHENK IST BEI BOMBSITE A`. Можно ввести `BOMBSITE A`.
4. Следующая загадка — ASCII: `00110011 00110100 00110010 00110111` → `3427`.
5. Физический замок чемодана заранее выставить на **3427**. Подарок положить
   у таблички **BOMBSITE A**. Дополнительные ответы BOCO, NAVI или 2626 не нужны.

Таблица Виженера — инструмент для игрока. Лист с готовым заданием Виженера и
подсказки лучше выдать только при открытии терминала после котов.

До замены файлов и Push эта сборка существует только в скачанном проекте.
Опубликованная версия изменится после успешного развёртывания GitHub Pages.

## Проверки

Пройдены проверки входа, недостающих файлов, шифров, трёх доставок и финальных
форм. В Chromium проверен полный переход от входа до подарка, настоящий ввод
с клавиатуры, повторное открытие финала, небольшие экраны ноутбука и сенсорные
экраны в двух ориентациях. Тесты выполняются через `npm test`;
расширенный браузерный тест — `npm run test:browser` после установки Playwright.
Мобильная проверка — эмуляция Chromium, не физический iPhone/Safari.
